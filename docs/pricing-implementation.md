# 新価格の実装（未公開）

## 確定ルール

ミラー施工は最新のユーザー回答に従い、**1枚につき5000円固定**。面積に依存しない。1枚5000円、2枚10000円、4枚20000円。取り外しありでは同額を追加する。

| 項目 | 新規見積 |
|---|---|
| 材料原価 | 平米単価×面積×枚数を明細で四捨五入 |
| 通常材料売価 | 材料原価×基本倍率1.5を四捨五入 |
| 修理材料売価 | 材料原価×1.10×基本倍率1.5を四捨五入。1.10分を仕入原価に加算しない |
| ミラー材料 | 工事区分が修理でも材料原価×1.5。1.10を加算しない |
| ガラス施工 | 指定済みの完成単価×面積×枚数。追加の×2なし |
| ミラー施工 | 5000×枚数 |
| 取り外し | 施工費と同額 |
| 元請けの材料・施工調整 | 新規の初期値1.0。旧1.25/1.75を重ねない |
| 元請けコーキング調整 | 既存1.48を維持 |

行ごとの手入力施工単価・材料倍率や売価直接入力は残す。意図的な個別調整は削除しない。旧見積には既存の価格ルール・倍率を適用する。

## 画面と保存

- 既存のカード入力、設定パネル、PDF2種類は維持。新価格にだけ「新築・通常 / 修理」の材料工事区分を追加。
- ページ起動と明細リセットで新規価格を選ぶ。旧案件の読込と別案件保存は旧価格を維持する。
- `settings.pricing` に計算ルール版とGP/CR/OTHERのコピーを格納し、`settings.calculated` に保存直前の計算結果を記録する。
- 読込では保存単価を使用し、現在の既定単価へ書き戻さない。新単価の既定保存は `usglass_master_2026_09`、標準倍率は `usglass_default_sell_mult_2026_09` を使用する。
- 旧キーと旧案件は新規初期化や新単価保存で削除・上書きしない。
- 価格版が不明または単価構造が壊れている場合は、価格を適用する前に拒否する。Drive読込失敗では現在案件IDを切り替えない。
- 旧案件に保存時単価がなければ復元不能な情報は推測しない。この端末の旧単価を使ったことを警告し、その未確認状態も保存する。

## 明確な限界

この変更で実務公開版は更新していない。旧公開版や `glass-quote.html` は新しい価格情報を理解しないため、改修版の新価格案件を旧画面で再編集しないこと。公開切替時には旧タブ・別版の運用整理が必要。

Driveは引き続き全件JSON方式で、同時編集の競合対策・自動保存・履歴は未実装。将来版のマスターを現在版へ自動移行する機能もない。単価情報のない旧見積の正確な保存時金額は、元PDFとの照合が必要。

新規の通常材料の原価は修理用1.10を含まなくなるため、旧方式と材料原価・粗利が変わる。これは正式新ルールへの意図した変更。追加費用の原価を実NET粗利が差し引かない既存差異は、この段階では変更していない。
