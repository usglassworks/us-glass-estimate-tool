# US GLASS ガラス積算ツール

既存の実務用HTMLアプリです。画面や計算を全面的に置き換えず、段階的に改善します。

## このブランチの範囲

基準コミット: `4fc91fe4075a00e2f44e8d54b3c13580fdeb7e19`

回帰テストに加え、新規見積の価格ルールを実装しています。安定版へのマージ・公開反映は行っていません。PDF生成処理と既存の画面構成は維持しています。

**最新の確定事項：ミラー施工は1枚につき5,000円です。** 新規見積では材料の基本倍率1.5、修理材料のみ1.10、施工は指定の完成単価を使用します。元請けのガラス・施工の初期調整倍率は1.0。コーキングの提出倍率1.48は維持します。

`pricing/master-2026-09.json` が正式な基準データです。ブラウザ用の `pricing/approved-master.js` は `node scripts/build-price-context.cjs` で生成します。旧公開版へJSONだけをインポートしても新計算ルールにはなりません。

旧見積を開くと旧ルールを使用します。新しい保存では単価と計算ルールを記録します。単価情報がない古い見積は端末の旧単価で再計算するため、元のPDFとの照合が必要です。

## テスト

Node.js 22以上で、リポジトリのルートから実行します。npmパッケージのインストールは不要です。

```sh
node --test tests/*.test.cjs
```

- 実際の `index.html` からJavaScriptを読み込み、計算関数を実行します。
- 仮の代表案件21件について、改修前の結果と比較します。実際の顧客データではありません。
- Google Driveはメモリ上の代替処理で検証します。実アカウントへ接続・保存・削除しません。
- 指定の材料29項目・施工24項目・その他6項目を照合し、施工費・取り外し費に追加の×2が掛からないことを確認します。
- 現行の問題を記録するテストは、その挙動を将来も維持すべきという意味ではありません。新価格用テストと旧価格互換テストを分けて、意図した変更をレビューします。

認証画面、iPhone実機、PDFの見た目、実際の保存見積の復元は、この自動テストの対象外です。
